# Notifyer — быстрые заметки в Obsidian и напоминания

Дата: 2026-11-19. Платформа: Windows 11. Стек: Tauri 2 (Rust) + React + TypeScript.

## Цель

Лёгкое приложение в трее: по горячей клавише мгновенно открывается строка ввода,
мысль пишется прямо в хранилище Obsidian (сам Obsidian запускать не нужно).
Если во фразе есть дата/время — дополнительно создаётся напоминание, которое
показывается красивым попапом поверх всех окон.

## Поведение

### Окно ввода
- Глобальная клавиша `Ctrl+Alt+N` (меняется в `config.json`). Повторное нажатие — скрыть.
- Окно без рамки, по центру экрана, поверх всех. `Esc` или потеря фокуса — скрыть.
- `Enter` — сохранить. Пустой текст не сохраняется.
- Если распознана дата — под полем подсказка `⏰ чт, 20 ноя, 15:00` и чипы смещений:
  `1 день`, `1 ч`, `30 мин`, `15 мин`, `5 мин`. По умолчанию включены значения из
  `config.defaultOffsets` (`[60, 30, 5]` минут). Срабатывание в сам момент события — всегда.
- Пока поле пустое — под ним список ближайших напоминаний с кнопкой удаления.
- Фраза даты вырезается из текста напоминания: `завтра в 15 созвон` → `Созвон`.

### Распознавание дат (русский)
- День: `сегодня`, `завтра`, `послезавтра`; дни недели (`пн`…`вс`, полные формы, с `в`/`во` и без);
  `20.11`, `20.11.2026`, `20 ноября`, `20 ноя`.
- Время: `в 15`, `в 15:30`, `15:30`, модификаторы `утра/дня/вечера/ночи`.
- Относительное: `через 10 мин`, `через 2 часа`, `через час`, `через полчаса`, `через 3 дня`.
- Только время → сегодня, если ещё не прошло, иначе завтра. Только день → 09:00.
- День недели → ближайший такой день в будущем (сегодня, если время ещё не прошло).
- Дата без года → ближайшая в будущем.

### Запись в Obsidian
- Хранилище определяется автоматически из `%APPDATA%\obsidian\obsidian.json`
  (открытое, иначе последнее), может быть переопределено `config.vaultPath`.
- Файл `<vault>/<config.inboxFolder = "Входящие">/YYYY-MM-DD.md`, дописывание строк:
  - заметка: `- 20:31 текст`
  - с напоминанием: `- [ ] 20:35 Созвон с Петей ⏰ 2026-11-20 15:00`

### Напоминания
- Хранятся в `%APPDATA%\dev.notifyer.app\reminders.json`: `id, text, due (unix ms), offsets (мин), fired (мин)`.
- Планировщик в Rust проверяет каждые 5 секунд. Триггер `offset` срабатывает при `now >= due - offset`.
- Пропущенные (компьютер был выключен): предварительные триггеры, просроченные больше чем на 2 минуты,
  тихо помечаются сработавшими; основной (offset 0) показывается всегда.
- После срабатывания основного триггера напоминание удаляется.

### Попап
- Окно без рамки, поверх всех, не забирает фокус, справа сверху над панелью задач.
- Стопка карточек: заголовок (`Через 30 минут` / `Сейчас`), текст, полоса таймера.
- Каждая карточка скрывается через 15 секунд. Кнопки: `Готово`, `+10 мин`, `+1 час`
  (отложить = новое напоминание без предварительных триггеров).

### Трей и запуск
- Меню: `Новая заметка`, `Открыть конфиг`, `Выход`. Клик по значку — окно ввода.
- Автозапуск с Windows (plugin-autostart), единственный экземпляр (plugin-single-instance).

### Конфиг `%APPDATA%\dev.notifyer.app\config.json`
`hotkey`, `vaultPath` (null = авто), `inboxFolder`, `defaultOffsets`. Применяется после перезапуска.

## Архитектура
- Rust: `config.rs` (конфиг, поиск хранилища), `vault.rs` (запись строк),
  `reminders.rs` (модель, хранилище, чистая логика триггеров + тесты), `scheduler.rs` (поток),
  `lib.rs` (окна, трей, клавиша, команды).
- Frontend: одна точка входа, роутинг по label окна (`quick` / `popup`);
  `lib/parseDate.ts` (чистая функция + тесты vitest), `lib/api.ts` (обёртки invoke).
- Попап забирает очередь через `popup_take_pending` по событию `popup-ping` и при монтировании
  (не теряем события, отправленные до готовности окна).

## Вне MVP
Окно настроек, повторяющиеся напоминания, обратная синхронизация галочек из Obsidian, macOS/Linux.
